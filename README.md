# AI Proposal / Quotation Generator (Commented Version)

This version of the project is designed for learning and interview preparation.

It includes:
- full working code
- heavy inline comments in every main Python file
- menu-based input flow
- local JSON mock data
- optional public API connector
- mock LLM provider
- optional Ollama provider
- JSON, TXT, and HTML outputs
- interview-focused architecture guide

## Run

```bash
python app.py
```

## Sample mode

```bash
python app.py --sample
```

## Public API mode

```bash
python app.py --public
```

## Ollama mode

```bash
python app.py --ollama
```
